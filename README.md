# Text-to-SQL Query Generator

An AI-powered application that converts natural language questions into SQL queries using Large Language Models (LLMs), enabling users to interact with databases using plain English.

## Features
- Natural language to SQL query generation
- Database schema-aware query generation
- Agent-based processing
- Benchmarking and evaluation support

## Tech Stack
- Python
- Large Language Models (LLMs)
- SQL
- Prompt Engineering

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Rashmi-Nitor/Text-to-Sql-.git
cd Text-to-Sql-
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```
